# Hidden Replay Infrastructure

This package is retained as implementation support for multiscale refiner data
construction. It provides normalized Camera token loading, Camera Head hidden
capture, frame-matched intervention, replay, and artifact validation.

The attribution, causal-preference, replacement, and adaptive-alpha studies are
complete. Their AutoDL launchers, published results, and historical instructions
are intentionally excluded from this branch. New workflow entry points must not
be added here; place them under `camera_refiner_data_construction/`.
